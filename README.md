# rankbound

A package for computing upper bounds on the Mordell-Weil ranks of elliptic curves $E$ over ℚ, with independent witnesses.

For curves with 2-torsion, `rankbound` bounds the rank unconditionally by descent via 2-isogeny. For curves without 2-torsion, the bound depends on the GRH for the Dedekind zeta functions of unramified quadratic extensions of the cubic field $F_E$ generated by a root of the 2-division polynomial of $E$, following \[[KSW19](#ksw19), [BDF08](#bdf08)\]. It does not require the BSD conjecture.

## Database

The database covers the 8,172 curves of ICARM's [Elliptic Curve Rank Leaderboard](https://elliptic-rank.icarm.cloud/) submitted before 11/26/2026 00:00 UTC.
For each curve, it gives the rank lower bound $r$ from ICARM's points, an upper bound $S$, and whether
$\mathrm{rank}~E(\mathbb{Q}) = r$ is proved. For the 4,419 curves with rational 2-torsion, the bound is unconditional,
and every one is sharp.

For the 3,753 curves without rational 2-torsion, the bound assumes the GRH. Here, 3,745 have a sharp proven rank, four have
a non-sharp upper bound, and four were not bounded. Of the four, #289 had a
discriminant too large to be factored, #374 and #443 gave too few relations, and the cubic field of #568 has a coefficient
too large for the siever. We obtained sharp upper bounds for the rank of every curve on ICARM of rank 31 and rank 32.

For each curve, we store a *witness*, or a JSON file proving its rank upper bound. For curves with rational 2-torsion,
each witness contains the bases of its Selmer groups and the data of its pairings. For curves without 2-torsion, each
witness contains the curve's relations and the steps of Gaussian elimination that prove its bound. The witnesses are on
[Zenodo](https://doi.org/10.5281/zenodo.23479585), where the witnesses for each curve on ICARM can be installed. For
example, to install the witness for curve #3862 (rank 28), download `icarm_rank28.json.gz` and run:

```
rankbound unpack icarm_rank28.json.gz --ids 3862
rankbound check witnesses/icarm3862.witness.json.gz
```

## Requirements

- Python 3.9 or later
- A C compiler
- PARI/GP 2.17 or later (optional for checking witnesses)
- GMP-ECM (optional)

## Installation

To install the latest version from GitHub, run

```
pip install git+https://github.com/rjain2470/rankbound
```

This compiles the native programs and installs the `rankbound` command. To work from a clone of the repository
instead, run

```
make build
make test
pip install .
```

## Quickstart

### Bounding a rank

Consider the elliptic curve

$$E: y^2 + y = x^3 - x^2 - 929x - 10595$$

of conductor 571. To bound its rank, give `rankbound bound` its a-invariants $a_1, a_2, a_3, a_4, a_6$:

```
$ rankbound bound 0,-1,1,-929,-10595
10:45:12 Conductor 571, one bad prime, root number +1, no rational 2-torsion.
10:45:12 Sieving for relations. This should take under a minute.
10:45:12 Found 28,830 relations so far in 0.00 core-hours.
10:45:12 Solving the linear system of 28,830 relations.
10:45:12 Sieving is finished with 28,830 relations in 0.00 core-hours.
10:45:12 Writing the witness from the relations of the last check.
10:45:13 Rank at most 2. Verification method: 2-Selmer group (assuming the GRH).
10:45:13 Rank at most 0. Verification method: Cassels-Tate pairing (assuming the GRH).
10:45:14 Rank 0, assuming the GRH. Witness: rankbound_work/0_-1_1_-929_-10595/0_-1_1_-929_-10595.witness.json.gz (checked)
```

Since $E$ has no rational 2-torsion, `rankbound` sieves for relations in the cubic field $F_E$ and uses them to show
that $\dim \mathrm{Sel}_2(E) \le 2$.

### Checking a witness

Using `rankbound`, one can also check witnesses independently of the code used to generate them. For example, the
following code checks a witness verifying that the elliptic curve $E: y^2 + y = x^3 - x^2 - 929x - 10595$ has rank
exactly 0 assuming the GRH:

```
$ rankbound check rankbound_work/0_-1_1_-929_-10595/0_-1_1_-929_-10595.witness.json.gz
10:45:14 Checker 192362ff127cff91 with PARI/GP 2.17.4, 24 November 2026 at 10:45 AM. Witness sha256 d56422910d92c440788ebb1b880a55952d1305f6913b31ba068cd9747f4f7572.
10:45:14 0_-1_1_-929_-10595 passes in 0 seconds. Rank 0 (assuming the GRH).
```

The first line records what the verdict depends on: the checker's source code (by its hash), the version of PARI/GP,
and the witness (by its sha256). The second line gives the verdict and the statement proved.

### More options

```
rankbound bound <a-invariants> --points points.txt   # also prove rank >= r from r points, one "x y" per line
rankbound bound <a-invariants> --uncond              # a bound without the GRH, for cubic fields of small discriminant
rankbound bound <a-invariants> --estimate            # the expected cost, without running
rankbound bound --help                               # every option
```

Running the same command again resumes an interrupted run.
