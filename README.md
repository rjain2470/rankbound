# rankbound

A package for computing upper bounds on ranks of elliptic curves $E$ over ℚ, certified by an independent
check in PARI/GP.

Following \[[KSW19](#ksw19), [BDF08](#bdf08)\], the bound depends on the GRH for the Dedekind zeta functions of finitely
many unramified quadratic extensions of the cubic field $F_E$ generated by a root of the 2-division polynomial of $E$.

The method only applies to curves without rational points of order 2. For curves with 2-torsion, descent via
2-isogeny (e.g. Cremona's `mwrank`) bounds the rank unconditionally.

## Database

`certificates.tsv` lists 1,964 curves from ICARM's Elliptic Curve Rank Leaderboard, which includes all submitted
curves up to 10/18/2026 without rational 2-torsion. For all but four curves, it gives the rank lower bound $r$ from
ICARM's points, the upper bound $S$ under GRH, and whether $\mathrm{rank}~E(\mathbb{Q}) = r$ is proved. Of these, 1,911
have $\mathrm{rank}~E(\mathbb{Q}) = r$ under GRH and 49 have $r \le \mathrm{rank}~E(\mathbb{Q}) \le S$. Of the four
which were not checked, one, #289, had a discriminant too large to be factored, and the other three (#374, #443, #568)
had fields which could not be sieved by CADO-NFS.

For each curve with a rank upper bound under GRH, we store a JSON file containing its relations and the
steps of Gaussian elimination that prove its bound, which we call a *certificate*. The certificates for all 1,960 of
these curves are on Zenodo: https://doi.org/10.5281/zenodo.23479586. To check them, run the following code in the folder of
the downloaded record with this repository at `RANKBOUND`:

```
gunzip certificates/*.cert.json.gz
awk -F'\t' 'NR > 1 && $3 {print $7 "  certificates/" $3}' RANKBOUND/certificates.tsv | shasum -a 256 -c
rankbound verify --cores 4 certificates/
```

## How it works

Let $E$ be an elliptic curve over ℚ without 2-torsion with $F_E$ as above. By the Brumer–Kramer bound,

$$\mathrm{rank}~E(\mathbb{Q}) \le \dim \mathrm{Sel}_2(E) \le \dim \mathrm{Cl}(F_E)[2] + c$$

for a computable constant $c$, so it suffices to bound $\dim \mathrm{Cl}(F_E)[2]$. Assuming GRH, the class group of $F_E$ modulo squares is spanned by the
ideal classes of the $N$ prime ideals of $F_E$ with norm below an explicit bound \[[BDF08](#bdf08)\]. Thus,
$\dim \mathrm{Cl}(F_E)[2]$ is at most $N$, so we obtain $\mathrm{rank}~E(\mathbb{Q}) \le N + c$.

To lower this bound, `rankbound` searches for *relations*, or pairs of integers $(a, b)$ such that for a fixed
generator $\alpha$ of $F_E$, $(a - b\alpha)$ factors into these $N$ prime ideals. Since $(a - b\alpha)$ is
principal, the exponents of its factors modulo 2 give a linear relation among their classes modulo squares. Given $d$
independent relations, we have $\mathrm{rank}~E(\mathbb{Q}) \le N - d + c$. Oftentimes (but not always), this algorithm gives a sharp upper
bound on $\mathrm{rank}~E(\mathbb{Q})$.

`rankbound` also includes an independent verifier, which automatically checks a rank upper bound given a curve, its
relations, and the steps of the Gaussian elimination over ℤ/2ℤ that combine them. This
verifier recomputes $F_E$, $N$, and $c$ in PARI/GP, checks each factorization, and recomputes $d$
with its own linear algebra.

## Example

Consider the curve

$$E: y^2 + y = x^3 - x^2 - 929x - 10595.$$

To compute an upper bound on $\mathrm{rank}~E(\mathbb{Q})$, run:

```
$ rankbound bound 0,-1,1,-929,-10595
22:45:24 Aim: rank <= 0 (the least possible). Stops there or when the bound stops improving.
22:45:24 Estimated cost: 0.00 core-hours (0.00 h on 1 core).
22:45:34 10,407 relations: rank <= 2 so far (aim: rank <= 0).
22:46:02 12,052 relations: rank <= 2 so far (aim: rank <= 0).
22:46:02 No progress; checking once more with every relation kept.
22:46:02 Sieving finished: 12,052 relations, 0.01 core-hours.
22:46:02 Certificate: /.../rankbound_work/0_-1_1_-929_-10595/0_-1_1_-929_-10595.cert.json
22:46:02 RESULT 0_-1_1_-929_-10595: rank <= 2 under GRH, certificate verified (0.01 core-h)
```

The certificate keeps the 37 relations the proof needs, and the verifier recomputes everything else:

```
$ rankbound verify rankbound_work/0_-1_1_-929_-10595/0_-1_1_-929_-10595.cert.json
22:46:02 Verifier 01402f95e30e00b6, PARI/GP 2.17.4, 2026-10-18 22:46:02 -0400. Certificate sha256 b0aa2cf9…
22:46:02 PASS: 0_-1_1_-929_-10595 (0 s). Assuming the GRH, we have that rank E(Q) <= 2.
```

Here the bound equals $\dim \mathrm{Sel}_2(E)$, so no 2-descent can do better: $\mathrm{rank}~E(\mathbb{Q}) = 0$,
and the 2-torsion $\text{Ш}(E)[2]$ of its Tate–Shafarevich group has order 4 \[[Cre97](#cre97)\].

Given the relations of a certificate, `rankbound` proves the same bound without sieving:

```
$ rankbound bound 0,-1,1,-929,-10595 --relations rankbound_work/0_-1_1_-929_-10595/0_-1_1_-929_-10595.cert.json
22:46:12 Aim: rank <= 0 (the least possible). Stops there or when the bound stops improving.
22:46:12 37 relations: rank <= 2 (aim: rank <= 0).
22:46:12 Certificate: /.../rankbound_work/0_-1_1_-929_-10595_rel851f7108/0_-1_1_-929_-10595.cert.json
22:46:12 RESULT 0_-1_1_-929_-10595: rank <= 2 under GRH, certificate verified (0.00 core-h)
```

Given $r$ independent rational points, the certificate also proves $\mathrm{rank}~E(\mathbb{Q}) \ge r$. For the
curve $E: y^2 + y = x^3 + x^2 - 2x$, with the points $(-1, 1)$ and $(0, 0)$ in `points.txt`, this proves
$\mathrm{rank}~E(\mathbb{Q}) = 2$:

```
$ rankbound bound 0,1,1,-2,0 --points points.txt --compute
21:35:58 Aim: rank <= 2 = r, which proves rank = 2.
21:35:58 Estimated cost: 0.00 core-hours (0.00 h on 1 core).
21:36:07 11,952 relations: rank <= 2 so far (aim: rank <= 2).
21:36:07 Sieving finished: 11,952 relations, 0.00 core-hours.
21:36:07 Certificate: /.../rankbound_work/0_1_1_-2_0_r2p/0_1_1_-2_0.cert.json
21:36:08 RESULT 0_1_1_-2_0: rank = 2 under GRH, certificate verified (0.00 core-h)
```

Curves already certified (listed in `certificates.tsv`) are looked up rather than computed; `--compute`, as above,
computes anyway:

```
$ rankbound bound 0,1,1,-2,0
21:36:08 icarm2 is already certified: rank E(Q) = 2 under GRH. Nothing was computed.
```

## Requirements

- PARI/GP 2.17 or later
- Python 3.9 or later (standard library only)
- a C compiler
- for large fields only (when the bound of \[[BDF08](#bdf08)\] exceeds $2^{11}$): CADO-NFS at commit `692ecb7e62f0f3bdab88ee44cc60b8ded0ea1a1b`, whose build
  needs cmake 3.18 or later, GMP and a C++20 compiler

Checking a certificate needs only PARI/GP, Python and a C compiler.

## Installation

```
make build        # compile f2elim and f2rank (before pip install)
make test         # about 3 minutes
pip install .     # optional: the `rankbound` command; otherwise use `python3 -m rankbound`
```

For large fields, build CADO-NFS into `rankbound/cado/` with `make cado CADO_TARBALL=cado-nfs.tar.gz`. Build it on
the oldest CPU it will run on; on macOS, set `CXXFLAGS="-std=c++20 -fexperimental-library"`.

An installed copy does not include:

- CADO-NFS: set `RANKBOUND_CADO` to the checkout's `rankbound/cado`.
- `certificates.tsv`: curves are computed, never looked up.

## Usage

| command | description |
|---|---|
| `rankbound bound <a-invariants>` | bound the rank and write a certificate |
| `rankbound estimate <a-invariants>` | estimate the cost, without running |
| `rankbound status [<folder>]` | show the progress of the runs in a work folder |
| `rankbound verify <certificate>...` | check certificates |

Here, `<a-invariants>` can be a list of the form `a1,a2,a3,a4,a6` or `a4,a6`, on any model; `<folder>` is a work
folder (default `./rankbound_work`); and `<certificate>` is a `.cert.json` file or a folder of them. Running the same
`bound` command again resumes an interrupted run.

`rankbound bound` also takes the following options:

```
--r R               a known lower bound r on the rank: stop once the bound is r
--points FILE       r independent points, one "x y" per line: also prove rank >= r
--relations FILE    prove the bound from these relations, without sieving
--bad-primes P,...  the primes of the discriminant, if it is hard to factor
--curves FILE       several curves from a JSON list (select with --ids)
--cores N           number of cores
--max-hours H       stop after H hours (run again to resume)
--compute           compute even if the curve is already certified
```

`rankbound <command> --help` lists every option. A curve list is
`{"curves": [{"id": 1, "ainvs": [...], "bad_primes": [...]}, ...]}`, where `bad_primes` lists every prime of the
discriminant. The exit status is 0 on success, 1 on a refused curve or a failed check, and 2 on a usage error.

From Python:

```python
from rankbound import rankbound

res = rankbound([0, -1, 1, -929, -10595])
res.rank_bound, res.verified        # (2, True)
```

On a cluster, `bound` stops five minutes before a Slurm job's time limit, and resubmitting resumes; a large field can
be split over machines with `rankbound sieve <folder> --shard K/N`. To check a submitted certificate against its
curve, with limits on size and time:

```
rankbound verify --json --curve a1,a2,a3,a4,a6 --max-mb 50 --max-seconds 600 NAME.cert.json
```

`rankbound` also includes an independent verifier at `rankbound/verify/`, which:

- recomputes the cubic field, the local terms, the root number and the GRH bound of \[[BDF08](#bdf08)\];
- checks the factorization of every relation;
- recomputes the rank over ℤ/2ℤ with its own code.

Each certificate gets one verdict: PASS (exit status 0) when every check passes; FAIL (1) when a check fails, the
file is malformed, or it is for a curve other than `--curve`; and NOT CHECKED when it is over `--max-mb` or
`--max-seconds` (3) or the verifier could not run (4). `--json` prints one JSON object per certificate, with every
check.
